Uji di browser:
Dialog produk tampil, pencarian “Lisensi” menyisakan 2 baris.
Dua produk dicentang lalu dipilih menjadi 2 baris item, harga terisi, dan total terhitung Rp2.650.000.

Lookup karyawan untuk field Pemohon mengisi nama otomatis.
Cara kerjanya generik. Kolom, kolom pencarian, dan urutan di dialog diambil dari listView DocType target. Jadi Product, Employee, Vendor, atau DocType baru apa pun langsung bisa, cukup diaktifkan lewat metadata. Datanya diambil lewat DocumentService.ListAsync, sehingga isolasi tenant, cakupan baris, dan permission field tetap berlaku di dalam dialog.

Ada dua mode pemakaian:

"lookupDialog": true pada field Link. Muncul tombol daftar di samping combobox; klik satu baris untuk memilih.
"addFromLookup" pada field Table. Muncul tombol “Tambah produk”; centang beberapa baris, dan setiap pilihan menjadi satu baris item dengan field yang dipetakan.

@code {
    /// <summary>DocType yang ditampilkan, mis. "Product" atau "Employee".</summary>
    [Parameter, EditorRequired] public string Target { get; set; } = "";
    [Parameter] public bool Open { get; set; }
    [Parameter] public EventCallback<bool> OpenChanged { get; set; }
    [Parameter] public bool Multiple { get; set; }
    [Parameter] public string? Title { get; set; }
    /// <summary>Filter tetap, mis. hanya karyawan aktif: [new("active", "=", true)].</summary>
    [Parameter] public IReadOnlyList<FilterClause>? Filters { get; set; }
    /// <summary>Nama dokumen yang tidak boleh dipilih lagi (mis. produk yang sudah ada di tabel).</summary>
    [Parameter] public IReadOnlySet<string>? Exclude { get; set; }
    /// <summary>Baris terpilih (berisi kolom list view + "name"). Gunakan nama untuk memuat dokumen lengkap bila perlu.</summary>
    [Parameter] public EventCallback<IReadOnlyList<Dictionary<string, object?>>> OnSelected { get; set; }
    [Parameter] public int PageSize { get; set; } = 10;

    private CompiledDocType? TargetMeta;
    private ListResponse? result;
    private string? search, error;
    private bool wasOpen;
    private readonly Dictionary<string, Dictionary<string, object?>> selected = new();

    private int TotalPages => result is null ? 0 : (int)Math.Ceiling(result.Total / (double)result.PageSize);
    private bool IsNum(string c) => TargetMeta!.ByName.GetValueOrDefault(c)?.Type.Editor == "number";
    private string LabelOf(string f) => f == "name" ? "Nomor" : TargetMeta!.ByName.TryGetValue(f, out var cf) ? cf.Label : f;

    protected override async Task OnParametersSetAsync()
    {
        Metadata.Current.TryGet(Target, out TargetMeta);
        // Setiap kali dialog dibuka: reset pilihan & pencarian, muat halaman pertama.
        if (Open && !wasOpen)
        {
            selected.Clear(); search = null; result = null;
            await Load(1);
        }
        wasOpen = Open;
    }

    private Task OnSearch(string? v) { search = v; return Load(1); }

    private async Task Load(int page)
    {
        try
        {
            error = null;
            result = await Docs.ListAsync(Current.Required, Target, new ListRequest(Filters, search, null, null, page, PageSize));
        }
        catch (Exception ex) when (ex is PermissionDeniedException or InvalidPayloadException or DocumentNotFoundException)
        {
            error = ex.Message;
        }
    }

    private async Task RowClicked(Dictionary<string, object?> row)
    {
        var name = (string)row["name"]!;
        if (Exclude?.Contains(name) == true) return;
        if (Multiple) { Toggle(row, !selected.ContainsKey(name)); return; }
        await OnSelected.InvokeAsync([row]);
        await OnOpenChanged(false);
    }

    private void Toggle(Dictionary<string, object?> row, bool on)
    {
        var name = (string)row["name"]!;
        if (on) selected[name] = row; else selected.Remove(name);
    }

    private async Task Confirm()
    {
        await OnSelected.InvokeAsync(selected.Values.ToList());
        await OnOpenChanged(false);
    }

    private async Task OnOpenChanged(bool open)
    {
        Open = open; wasOpen = open;
        await OpenChanged.InvokeAsync(open);
    }
}

csharp
    private bool lookupOpen;
    private LookupAddDef? Lookup => Table.Def.AddFromLookup;
    private string? LookupTarget => Lookup is null ? null : ChildMeta.ByName.GetValueOrDefault(Lookup.LinkField)?.Def.LinkTo;

    /// <summary>Dokumen yang sudah ada di tabel tidak bisa dipilih lagi.</summary>
    private IReadOnlySet<string> ExistingLinks =>
        Rows.Select(r => r.GetValueOrDefault(Lookup!.LinkField) as string).OfType<string>().ToHashSet();

    /// <summary>Satu baris baru per dokumen terpilih: isi field Link, lalu salin field sesuai addFromLookup.map.</summary>
    private async Task AddFromLookup(IReadOnlyList<Dictionary<string, object?>> picked)
    {
        foreach (var p in picked)
        {
            var name = (string)p["name"]!;
            if (ExistingLinks.Contains(name)) continue;
            // Muat dokumen lengkap lewat DocumentService (permission & tenant tetap dicek), karena kolom list view
            // belum tentu memuat semua field yang dipetakan.
            var source = await Docs.GetAsync(Current.Required, LookupTarget!, name);
            var row = new Dictionary<string, object?>();
            foreach (var f in ChildMeta.Fields) row[f.Name] = Evaluator.DefaultFor(f, Current.Required);
            row[Lookup!.LinkField] = name;
            foreach (var (childField, sourceField) in Lookup.Map)
                if (ChildMeta.ByName.TryGetValue(childField, out var cf))
                {
                    var n = cf.Type.Normalize(source.Data.GetValueOrDefault(sourceField));
                    if (n.Ok && n.Value is not null) row[childField] = n.Value;
                }
            Rows.Add(row);
        }
        await OnChanged.InvokeAsync();
    }

Field filter harus tercantum di listView.filters, kolom list view, atau field standar DocType target. Selain itu, ListAsync menolaknya sebagai bagian dari allowlist keamanan.

Kolom dialog diatur dari metadata. Kolom yang tampil adalah field ber-inListView: true, atau listView.columns kalau diisi. Kolom pencarian diambil dari listView.searchFields.

Dialog hanya untuk memilih, keamanan tetap di server. Saat diuji, Andi bisa memilih “Joko” sebagai pemohon di dialog. Tapi saat disimpan, server tetap menolak karena aturan handler hanya mengizinkan pengajuan atas nama diri sendiri.
