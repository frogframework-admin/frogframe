 DocFrame (.NET 10 + Blazor Blueprint)

RINGKASAN
---------
Halaman Dashboard (/dashboard) berisi widget yang di-pin, dengan filter global
(tanggal mulai, tanggal akhir, departemen). System Manager membuat widget lewat
wizard 4 langkah (/dashboard/widgets/new):
  1. Query SQL ke view skema "reporting"; parameter @Nama dideteksi otomatis
     (di luar string literal & komentar).
  2. Tipe parameter (Teks/Angka/Tanggal/Boolean), nilai uji, binding ke filter
     dashboard atau konteks pengguna; pratinjau data grid (maks. 100 baris).
  3. Thumbnail grafik (Batang, Garis, Pie, Doughnut, Angka tunggal, Tabel) +
     pemetaan sumbu X (kategori) dan Y (wajib numerik); pratinjau langsung.
  4. Nama, deskripsi, role yang boleh melihat, tempel ke dashboard.
Konfigurasi disimpan sebagai JSON (docframe_dashboard_widgets.config).

KEAMANAN (berlapis)
  - Koneksi read-only TERPISAH, dan DIVERIFIKASI sebelum query: bukan superuser,
    tanpa INSERT/UPDATE/DELETE, tidak bisa membaca tabel dokumen/akun/sesi
    langsung, tidak bisa membuat objek. Gagal → dashboard menolak berjalan.
  - Isolasi tenant lewat tabel sesi yang diisi koneksi utama (dikunci per process
    id); set_config/SET dari dalam query tidak bisa mengganti tenant.
  - Transaksi READ ONLY + statement_timeout + rollback; dibungkus LIMIT.
  - Parameter dikirim native (Npgsql, bertipe), tidak pernah digabung ke SQL.
  - Hanya satu statement SELECT/WITH; dollar-quoting ditolak.
  - View hanya mengekspos field level izin 0 (field terbatas & gambar tidak).

SUDAH DIUJI
  - Test backend: 39 lulus (in-memory; test PostgreSQL dilewati) / 52 lulus
    (PostgreSQL + koneksi read-only), termasuk 7 test dashboard: deteksi parameter,
    isolasi tenant termasuk percobaan set_config & ubah tabel sesi, akses tabel akun
    & dokumen ditolak, DELETE di CTE ditolak, LIMIT, timeout, injeksi lewat nilai
    parameter, connection string non-read-only ditolak, binding filter, role widget,
    view diperbarui setelah publish metadata.
  - Uji browser 12 langkah (PostgreSQL): 6 widget contoh, filter departemen,
    DELETE & tabel akun ditolak dengan pesan jelas, wizard 4 langkah sampai pin,
    pengguna biasa hanya melihat widget sesuai role tanpa tombol desain.
  - Mode in-memory: menu Dashboard menampilkan pemberitahuan; semua uji UI lain lulus.

public sealed record SqlAnalysis(bool Ok, string? Error, string ParameterizedSql, IReadOnlyList<string> Parameters);

public static class SqlGuard
{
    public const int MaxLength = 10_000;

    /// <summary>
    /// Memindai query: @Nama di luar string literal, identifier berkutip, dan komentar diganti placeholder $1, $2, …
    /// (nama sama → nomor sama). Menolak lebih dari satu statement, dollar-quoting, dan perintah selain SELECT/WITH.
    /// Ini lapisan pertama; pertahanan utama tetap koneksi read-only + transaksi READ ONLY di eksekutor.
    /// </summary>
    public static SqlAnalysis Analyze(string? sql)
    {
        if (string.IsNullOrWhiteSpace(sql)) return Fail("Query kosong");
        if (sql.Length > MaxLength) return Fail($"Query melebihi {MaxLength} karakter");

        var sb = new StringBuilder(sql.Length);
        var names = new List<string>();
        var i = 0;
        var significant = new StringBuilder(); // teks tanpa string/komentar untuk cek keyword
        while (i < sql.Length)
        {
            var c = sql[i];
            if (c == '\'' || c == '"')
            {
                var start = i++;
                while (i < sql.Length)
                {
                    if (sql[i] == c) { if (i + 1 < sql.Length && sql[i + 1] == c) { i += 2; continue; } i++; break; }
                    i++;
                }
                if (i > sql.Length || sql[i - 1] != c || i - start < 2) return Fail(c == '\'' ? "String literal tidak ditutup" : "Identifier berkutip tidak ditutup");
                sb.Append(sql, start, i - start);
                significant.Append(c == '"' ? " ident " : " 'str' ");
                continue;
            }
            if (c == '-' && i + 1 < sql.Length && sql[i + 1] == '-')
            {
                while (i < sql.Length && sql[i] != '\n') sb.Append(sql[i++]);
                significant.Append(' ');
                continue;
            }
            if (c == '/' && i + 1 < sql.Length && sql[i + 1] == '*')
            {
                var end = sql.IndexOf("*/", i + 2, StringComparison.Ordinal);
                if (end < 0) return Fail("Komentar /* tidak ditutup");
                sb.Append(sql, i, end + 2 - i);
                i = end + 2;
                significant.Append(' ');
                continue;
            }
            if (c == '$' && i + 1 < sql.Length && (sql[i + 1] == '$' || char.IsLetter(sql[i + 1])))
                return Fail("Dollar-quoting ($$ … $$) tidak diizinkan");
            if (c == '$' && i + 1 < sql.Length && char.IsDigit(sql[i + 1]))
                return Fail("Gunakan parameter bernama @Nama, bukan $1");
            if (c == '@' && i + 1 < sql.Length && (char.IsLetter(sql[i + 1]) || sql[i + 1] == '_') && (i == 0 || !IsIdent(sql[i - 1]) && sql[i - 1] != '@'))
            {
                var start = ++i;
                while (i < sql.Length && IsIdent(sql[i])) i++;
                var name = sql[start..i];
                var idx = names.FindIndex(n => n.Equals(name, StringComparison.OrdinalIgnoreCase));
                if (idx < 0) { names.Add(name); idx = names.Count - 1; }
                sb.Append('$').Append(idx + 1);
                significant.Append(" $p ");
                continue;
            }
            if (c == ';')
            {
                var rest = sql[(i + 1)..];
                if (!string.IsNullOrWhiteSpace(StripComments(rest))) return Fail("Hanya satu statement yang diizinkan (hapus ';' di tengah query)");
                i++;
                continue; // titik koma penutup diabaikan
            }
            sb.Append(c);
            significant.Append(c);
            i++;
        }

        var first = FirstKeyword(significant.ToString());
        if (first is not ("select" or "with"))
            return Fail("Hanya query SELECT (atau WITH … SELECT) yang diizinkan");
        return new SqlAnalysis(true, null, sb.ToString().TrimEnd(), names);
    }

    private static bool IsIdent(char c) => char.IsLetterOrDigit(c) || c == '_';
    private static SqlAnalysis Fail(string e) => new(false, e, "", []);

    private static string FirstKeyword(string s)
    {
        var t = s.TrimStart(' ', '\t', '\r', '\n', '(');
        var end = 0;
        while (end < t.Length && char.IsLetter(t[end])) end++;
        return t[..end].ToLowerInvariant();
    }

    private static string StripComments(string s)
    {
        var sb = new StringBuilder();
        for (var i = 0; i < s.Length; i++)
        {
            if (s[i] == '-' && i + 1 < s.Length && s[i + 1] == '-') { while (i < s.Length && s[i] != '\n') i++; continue; }
            if (s[i] == '/' && i + 1 < s.Length && s[i + 1] == '*') { var e = s.IndexOf("*/", i + 2, StringComparison.Ordinal); i = e < 0 ? s.Length : e + 1; continue; }
            sb.Append(s[i]);
        }
        return sb.ToString();
    }
}

public interface IWidgetStore
{
    Task<IReadOnlyList<WidgetDef>> ListAsync(string tenantId, CancellationToken ct = default);
    Task<WidgetDef?> GetAsync(string tenantId, string id, CancellationToken ct = default);
    Task SaveAsync(WidgetDef widget, CancellationToken ct = default);
    Task DeleteAsync(string tenantId, string id, CancellationToken ct = default);
    Task<DashboardLayout> GetLayoutAsync(string tenantId, CancellationToken ct = default);
    Task SaveLayoutAsync(string tenantId, DashboardLayout layout, CancellationToken ct = default);
}

public sealed class InMemoryWidgetStore : IWidgetStore
{
    private readonly ConcurrentDictionary<(string, string), string> _widgets = new();
    private readonly ConcurrentDictionary<string, string> _layouts = new();

    private static WidgetDef Clone(WidgetDef w) => JsonSerializer.Deserialize<WidgetDef>(JsonSerializer.Serialize(w, DashboardJson.Options), DashboardJson.Options)!;

    public Task<IReadOnlyList<WidgetDef>> ListAsync(string tenantId, CancellationToken ct = default) =>
        Task.FromResult<IReadOnlyList<WidgetDef>>(_widgets.Where(kv => kv.Key.Item1 == tenantId)
            .Select(kv => JsonSerializer.Deserialize<WidgetDef>(kv.Value, DashboardJson.Options)!).OrderBy(w => w.Name).ToList());

    public Task<WidgetDef?> GetAsync(string tenantId, string id, CancellationToken ct = default) =>
        Task.FromResult(_widgets.TryGetValue((tenantId, id), out var j) ? JsonSerializer.Deserialize<WidgetDef>(j, DashboardJson.Options) : null);

    public Task SaveAsync(WidgetDef widget, CancellationToken ct = default)
    {
        _widgets[(widget.TenantId, widget.Id)] = JsonSerializer.Serialize(Clone(widget), DashboardJson.Options);
        return Task.CompletedTask;
    }

    public Task DeleteAsync(string tenantId, string id, CancellationToken ct = default) { _widgets.TryRemove((tenantId, id), out _); return Task.CompletedTask; }

    public Task<DashboardLayout> GetLayoutAsync(string tenantId, CancellationToken ct = default) =>
        Task.FromResult(_layouts.TryGetValue(tenantId, out var j) ? JsonSerializer.Deserialize<DashboardLayout>(j, DashboardJson.Options)! : new DashboardLayout());

    public Task SaveLayoutAsync(string tenantId, DashboardLayout layout, CancellationToken ct = default)
    {
        _layouts[tenantId] = JsonSerializer.Serialize(layout, DashboardJson.Options);
        return Task.CompletedTask;
    }
}

public sealed record DashboardFilters(DateOnly? Start, DateOnly? End, string? Department);

public sealed record WidgetRun(WidgetDef Widget, QueryResultSet? Result, string? Error);

public sealed class DashboardService(IWidgetStore store, IReportingQueryExecutor executor, TimeProvider clock,
    int previewLimit = 100, int widgetRowLimit = 1000)
{
    public bool IsAvailable => executor.IsAvailable;
    public const string DesignerRole = UserContext.SystemManager;

    public static bool CanDesign(UserContext user) => user.Roles.Contains(DesignerRole);

    private static void DemandDesigner(UserContext user)
    {
        if (!CanDesign(user)) throw new PermissionDeniedException("Merancang widget dashboard hanya untuk System Manager");
    }

    /// <summary>Langkah 1: deteksi parameter. Tipe awal ditebak dari nama (…Date/Tanggal → tanggal, Is…/Aktif → boolean).</summary>
    public static (SqlAnalysis Analysis, List<WidgetParameter> Parameters) DetectParameters(string sql, IReadOnlyList<WidgetParameter>? existing = null)
    {
        var a = SqlGuard.Analyze(sql);
        if (!a.Ok) return (a, []);
        var list = a.Parameters.Select(n => existing?.FirstOrDefault(p => p.Name.Equals(n, StringComparison.OrdinalIgnoreCase)) ?? new WidgetParameter
        {
            Name = n, Label = n,
            Type = n.Contains("date", StringComparison.OrdinalIgnoreCase) || n.Contains("tanggal", StringComparison.OrdinalIgnoreCase) ? ParamTypes.Date
                 : n.StartsWith("is", StringComparison.OrdinalIgnoreCase) || n.Contains("aktif", StringComparison.OrdinalIgnoreCase) ? ParamTypes.Boolean
                 : n.Contains("min", StringComparison.OrdinalIgnoreCase) || n.Contains("max", StringComparison.OrdinalIgnoreCase) || n.Contains("jumlah", StringComparison.OrdinalIgnoreCase) ? ParamTypes.Number
                 : ParamTypes.Text,
            Binding = n.Contains("start", StringComparison.OrdinalIgnoreCase) || n.Contains("mulai", StringComparison.OrdinalIgnoreCase) || n.Contains("dari", StringComparison.OrdinalIgnoreCase) ? ParamBindings.GlobalStart
                    : n.Contains("end", StringComparison.OrdinalIgnoreCase) || n.Contains("akhir", StringComparison.OrdinalIgnoreCase) || n.Contains("sampai", StringComparison.OrdinalIgnoreCase) ? ParamBindings.GlobalEnd
                    : ParamBindings.Default,
        }).ToList();
        return (a, list);
    }

    /// <summary>Konversi nilai teks ke tipe parameter. Gagal → pesan yang jelas (bukan dieksekusi sebagai teks).</summary>
    public static object? Convert(WidgetParameter p, string? raw)
    {
        if (string.IsNullOrWhiteSpace(raw)) return null;
        raw = raw.Trim();
        return p.Type switch
        {
            ParamTypes.Number => decimal.TryParse(raw.Replace(',', '.'), NumberStyles.Number, CultureInfo.InvariantCulture, out var d) ? d
                : throw new QueryRejectedException($"Parameter @{p.Name} harus angka"),
            ParamTypes.Date => DateOnly.TryParseExact(raw, "yyyy-MM-dd", CultureInfo.InvariantCulture, DateTimeStyles.None, out var dt) ? dt
                : throw new QueryRejectedException($"Parameter @{p.Name} harus tanggal yyyy-MM-dd"),
            ParamTypes.Boolean => raw.ToLowerInvariant() is "true" or "1" or "ya" ? true : raw.ToLowerInvariant() is "false" or "0" or "tidak" ? false
                : throw new QueryRejectedException($"Parameter @{p.Name} harus true/false"),
            _ => raw,
        };
    }

    private static string? BoundValue(WidgetParameter p, UserContext user, DashboardFilters? f) => p.Binding switch
    {
        ParamBindings.GlobalStart => f?.Start?.ToString("yyyy-MM-dd") ?? p.DefaultValue,
        ParamBindings.GlobalEnd => f?.End?.ToString("yyyy-MM-dd") ?? p.DefaultValue,
        ParamBindings.GlobalDepartment => string.IsNullOrWhiteSpace(f?.Department) ? p.DefaultValue : f!.Department,
        ParamBindings.UserId => user.Id,
        ParamBindings.UserDepartment => user.Attr("department") ?? p.DefaultValue,
        _ => p.DefaultValue,
    };

    private async Task<QueryResultSet> RunAsync(UserContext user, string sql, IReadOnlyList<WidgetParameter> parameters,
        Func<WidgetParameter, string?> valueOf, int limit, CancellationToken ct)
    {
        var a = SqlGuard.Analyze(sql);
        if (!a.Ok) throw new QueryRejectedException(a.Error!);
        var values = new List<SqlParam>();
        foreach (var name in a.Parameters)
        {
            var p = parameters.FirstOrDefault(x => x.Name.Equals(name, StringComparison.OrdinalIgnoreCase))
                ?? throw new QueryRejectedException($"Parameter @{name} belum didefinisikan");
            if (!ParamTypes.All.Contains(p.Type)) throw new QueryRejectedException($"Tipe parameter @{name} tidak dikenal");
            values.Add(new SqlParam(Convert(p, valueOf(p)), p.Type));
        }
        return await executor.ExecuteAsync(user.TenantId, a.ParameterizedSql, values, limit, ct);
    }

    /// <summary>Langkah 2: pratinjau dengan nilai uji (maks. previewLimit baris).</summary>
    public Task<QueryResultSet> PreviewAsync(UserContext user, string sql, IReadOnlyList<WidgetParameter> parameters, CancellationToken ct = default)
    {
        DemandDesigner(user);
        return RunAsync(user, sql, parameters, p => p.DefaultValue, previewLimit, ct);
    }

    public static IReadOnlyList<string> ValidateVisual(VisualConfig v, IReadOnlyList<ResultColumn> columns)
    {
        var errors = new List<string>();
        if (!ChartTypes.All.Contains(v.Type)) { errors.Add("Jenis grafik tidak dikenal"); return errors; }
        if (v.Type == ChartTypes.Table) return errors;
        var byName = columns.ToDictionary(c => c.Name, StringComparer.OrdinalIgnoreCase);
        if (v.Type is not ChartTypes.Number && (v.XColumn is null || !byName.ContainsKey(v.XColumn))) errors.Add("Pilih kolom sumbu X (kategori)");
        if (v.YColumns.Count == 0) errors.Add("Pilih minimal satu kolom nilai (sumbu Y)");
        foreach (var y in v.YColumns)
            if (!byName.TryGetValue(y, out var c)) errors.Add($"Kolom '{y}' tidak ada di hasil query");
            else if (c.Kind != "number") errors.Add($"Kolom '{y}' bukan angka — sumbu Y wajib numerik");
        if (v.Type is ChartTypes.Pie or ChartTypes.Doughnut or ChartTypes.Number && v.YColumns.Count > 1) errors.Add("Grafik ini hanya memakai satu kolom nilai");
        return errors;
    }

    /// <summary>Langkah 4: simpan. Query divalidasi ulang dan dijalankan sekali (dengan nilai default) agar konfigurasi pasti cocok dengan kolom.</summary>
    public async Task<WidgetDef> SaveAsync(UserContext user, WidgetDef widget, bool pin, CancellationToken ct = default)
    {
        DemandDesigner(user);
        if (string.IsNullOrWhiteSpace(widget.Name)) throw new QueryRejectedException("Nama widget wajib diisi");
        foreach (var p in widget.Config.Parameters)
            if (!ParamBindings.All.Contains(p.Binding)) throw new QueryRejectedException($"Binding parameter @{p.Name} tidak dikenal");
        var result = await RunAsync(user, widget.Config.Sql, widget.Config.Parameters, p => p.DefaultValue, 1, ct);
        var errors = ValidateVisual(widget.Config.Visual, result.Columns);
        if (errors.Count > 0) throw new QueryRejectedException(string.Join(" ", errors));

        var now = clock.GetUtcNow();
        var existing = string.IsNullOrEmpty(widget.Id) ? null : await store.GetAsync(user.TenantId, widget.Id, ct);
        widget.TenantId = user.TenantId; // tenant selalu dari identitas
        if (existing is null)
        {
            widget.Id = "w_" + Guid.NewGuid().ToString("N")[..12];
            widget.CreatedBy = user.Id; widget.CreatedAt = now; widget.Version = 1;
        }
        else
        {
            widget.CreatedBy = existing.CreatedBy; widget.CreatedAt = existing.CreatedAt; widget.Version = existing.Version + 1;
        }
        widget.UpdatedAt = now;
        await store.SaveAsync(widget, ct);
        if (pin) await PinAsync(user, widget.Id, ct);
        return widget;
    }

    public async Task<IReadOnlyList<WidgetDef>> ListAsync(UserContext user, CancellationToken ct = default) =>
        (await store.ListAsync(user.TenantId, ct)).Where(w => CanSee(user, w)).ToList();

    public static bool CanSee(UserContext user, WidgetDef w) =>
        CanDesign(user) || w.Config.Roles.Count == 0 || w.Config.Roles.Any(user.Roles.Contains);

    public async Task<WidgetDef?> GetAsync(UserContext user, string id, CancellationToken ct = default) =>
        await store.GetAsync(user.TenantId, id, ct) is { } w && CanSee(user, w) ? w : null;

    public async Task DeleteAsync(UserContext user, string id, CancellationToken ct = default)
    {
        DemandDesigner(user);
        await store.DeleteAsync(user.TenantId, id, ct);
        var layout = await store.GetLayoutAsync(user.TenantId, ct);
        if (layout.Items.RemoveAll(i => i.WidgetId == id) > 0) await store.SaveLayoutAsync(user.TenantId, layout, ct);
    }

    public Task<DashboardLayout> GetLayoutAsync(UserContext user, CancellationToken ct = default) => store.GetLayoutAsync(user.TenantId, ct);

    public async Task SaveLayoutAsync(UserContext user, DashboardLayout layout, CancellationToken ct = default)
    {
        DemandDesigner(user);
        foreach (var i in layout.Items) i.Span = Math.Clamp(i.Span, 1, 3);
        await store.SaveLayoutAsync(user.TenantId, layout, ct);
    }

    public async Task PinAsync(UserContext user, string widgetId, CancellationToken ct = default)
    {
        DemandDesigner(user);
        var layout = await store.GetLayoutAsync(user.TenantId, ct);
        if (layout.Items.All(i => i.WidgetId != widgetId)) layout.Items.Add(new DashboardItem { WidgetId = widgetId, Span = 1 });
        await store.SaveLayoutAsync(user.TenantId, layout, ct);
    }

    public async Task UnpinAsync(UserContext user, string widgetId, CancellationToken ct = default)
    {
        DemandDesigner(user);
        var layout = await store.GetLayoutAsync(user.TenantId, ct);
        layout.Items.RemoveAll(i => i.WidgetId == widgetId);
        await store.SaveLayoutAsync(user.TenantId, layout, ct);
    }

    /// <summary>Runtime: parameter diikat ke filter global dashboard / konteks pengguna, lalu dieksekusi.</summary>
    public async Task<WidgetRun> RunWidgetAsync(UserContext user, WidgetDef widget, DashboardFilters filters, CancellationToken ct = default)
    {
        if (!CanSee(user, widget)) return new WidgetRun(widget, null, "Anda tidak memiliki akses ke widget ini");
        try
        {
            var r = await RunAsync(user, widget.Config.Sql, widget.Config.Parameters, p => BoundValue(p, user, filters), widgetRowLimit, ct);
            return new WidgetRun(widget, r, null);
        }
        catch (Exception ex) when (ex is QueryRejectedException or ReportingUnavailableException)
        {
            return new WidgetRun(widget, null, ex.Message);
        }
    }
}

public sealed record ReportingView(string Name, string Title, IReadOnlyList<(string Column, string Type)> Columns);

public static class ReportingCatalog
{
    public static string SnakeCase(string pascal)
    {
        var sb = new StringBuilder();
        for (var i = 0; i < pascal.Length; i++)
        {
            if (char.IsUpper(pascal[i]) && i > 0 && !char.IsUpper(pascal[i - 1])) sb.Append('_');
            sb.Append(char.ToLowerInvariant(pascal[i]));
        }
        return sb.ToString();
    }

    /// <summary>Field yang diekspos ke view: hanya level izin 0; child table jadi view sendiri; gambar tidak diekspos.</summary>
    public static bool Exposed(CompiledField f) => f.Def.PermLevel == 0 && f.Def.Type is not ("Table" or "Image");

    public static string TypeLabel(CompiledField f) =>
        f.Type.ClrType == typeof(long) || f.Type.ClrType == typeof(decimal) ? "angka" : f.Type.ClrType == typeof(bool) ? "boolean" : f.Def.Type == "Date" ? "tanggal" : "teks";

    public static IReadOnlyList<ReportingView> Describe(MetadataSnapshot snap)
    {
        var list = new List<ReportingView>();
        foreach (var meta in snap.DocTypes.Values.Where(m => !m.Def.IsChild).OrderBy(m => m.Name))
        {
            var cols = new List<(string, string)> { ("name", "teks"), ("owner", "teks"), ("docstatus", "angka"), ("workflow_state", "teks"), ("created", "waktu"), ("modified", "waktu") };
            cols.AddRange(meta.Fields.Where(Exposed).Select(f => (f.Name, TypeLabel(f))));
            list.Add(new ReportingView($"reporting.{SnakeCase(meta.Name)}", meta.Title, cols));
            foreach (var t in meta.TableFields.Where(t => t.Def.PermLevel == 0))
                if (snap.TryGet(t.Def.ChildDocType!, out var child))
                {
                    var cc = new List<(string, string)> { ("parent", "teks"), ("idx", "angka") };
                    cc.AddRange(child.Fields.Where(Exposed).Select(f => (f.Name, TypeLabel(f))));
                    list.Add(new ReportingView($"reporting.{SnakeCase(meta.Name)}_{t.Name}", $"{meta.Title} · {t.Label}", cc));
                }
        }
        return list;
    }
}

/// <summary>
/// Membuat view reporting.&lt;doctype&gt; (dan reporting.&lt;doctype&gt;_&lt;tabel&gt; untuk child table) dari metadata aktif,
/// berisi kolom standar + field dengan tipe SQL yang sesuai. Field berlevel izin &gt; 0 dan field gambar tidak diekspos.
/// Setiap view memfilter tenant dari docframe_reporting_sessions → query user otomatis terbatas pada tenantnya.
/// </summary>
public sealed class ReportingSchemaSync(NpgsqlDataSource db, IMetadataProvider metadata, ReportingOptions options, ILogger<ReportingSchemaSync> log)
{
    private const long LockKey = 0x5265706F7274; // "Report"
    private int _subscribed;

    private static string Ident(string s) => "\"" + s.Replace("\"", "\"\"") + "\"";
    private static string Lit(string s) => "'" + s.Replace("'", "''") + "'";

    private static string Column(string source, CompiledField f)
    {
        var key = Lit(f.Name);
        return f.Type.ClrType == typeof(long) || f.Type.ClrType == typeof(decimal)
            ? $"CASE WHEN jsonb_typeof({source}->{key}) = 'number' THEN ({source}->>{key})::numeric END"
            : f.Type.ClrType == typeof(bool) ? $"CASE WHEN jsonb_typeof({source}->{key}) = 'boolean' THEN ({source}->>{key})::boolean END"
            : f.Def.Type == "Date" ? $"CASE WHEN ({source}->>{key}) ~ '^\\d{{4}}-\\d{{2}}-\\d{{2}}$' THEN ({source}->>{key})::date END"
            : $"({source}->>{key})";
    }

    private const string TenantFilter =
        "d.tenant_id = (SELECT s.tenant_id FROM public.docframe_reporting_sessions s WHERE s.pid = pg_backend_pid())";

    public async Task SyncAsync(CancellationToken ct = default)
    {
        var snap = metadata.Current;
        var ddl = new StringBuilder();
        var views = new List<string>();
        foreach (var meta in snap.DocTypes.Values.Where(m => !m.Def.IsChild))
        {
            var view = ReportingCatalog.SnakeCase(meta.Name);
            views.Add(view);
            var cols = new List<string> { "d.name", "d.owner", "d.docstatus", "d.workflow_state", "d.created", "d.modified" };
            cols.AddRange(meta.Fields.Where(ReportingCatalog.Exposed).Select(f => $"{Column("d.data", f)} AS {Ident(f.Name)}"));
            ddl.AppendLine($"CREATE VIEW reporting.{Ident(view)} AS SELECT {string.Join(", ", cols)} FROM public.docframe_documents d " +
                           $"WHERE d.doctype = {Lit(meta.Name)} AND {TenantFilter};");
            ddl.AppendLine($"COMMENT ON VIEW reporting.{Ident(view)} IS {Lit($"{meta.Title} (DocType {meta.Name} v{meta.Version})")};");
            foreach (var t in meta.TableFields.Where(t => t.Def.PermLevel == 0))
            {
                if (!snap.TryGet(t.Def.ChildDocType!, out var child)) continue;
                var cview = $"{view}_{t.Name}";
                views.Add(cview);
                var key = Lit(t.Name);
                var ccols = new List<string> { "d.name AS parent", "r.ordinality::integer AS idx" };
                ccols.AddRange(child.Fields.Where(ReportingCatalog.Exposed).Select(f => $"{Column("r.value", f)} AS {Ident(f.Name)}"));
                ddl.AppendLine($"CREATE VIEW reporting.{Ident(cview)} AS SELECT {string.Join(", ", ccols)} FROM public.docframe_documents d " +
                               $"CROSS JOIN LATERAL jsonb_array_elements(CASE WHEN jsonb_typeof(d.data->{key}) = 'array' THEN d.data->{key} ELSE '[]'::jsonb END) WITH ORDINALITY AS r(value, ordinality) " +
                               $"WHERE d.doctype = {Lit(meta.Name)} AND {TenantFilter};");
            }
        }

        await using var conn = await db.OpenConnectionAsync(ct);
        await using var tx = await conn.BeginTransactionAsync(ct);
        await Exec(conn, tx, $"SELECT pg_advisory_xact_lock({LockKey})", ct);
        await Exec(conn, tx, "CREATE SCHEMA IF NOT EXISTS reporting", ct);
        var existing = new List<string>();
        await using (var cmd = new NpgsqlCommand("SELECT viewname FROM pg_views WHERE schemaname = 'reporting'", conn, tx))
        await using (var r = await cmd.ExecuteReaderAsync(ct))
            while (await r.ReadAsync(ct)) existing.Add(r.GetString(0));
        foreach (var v in existing) await Exec(conn, tx, $"DROP VIEW IF EXISTS reporting.{Ident(v)} CASCADE", ct);
        await Exec(conn, tx, ddl.ToString(), ct);

        bool roleExists;
        await using (var cmd = new NpgsqlCommand("SELECT EXISTS (SELECT 1 FROM pg_roles WHERE rolname = $1)", conn, tx))
        {
            cmd.Parameters.AddWithValue(options.ReadOnlyRole);
            roleExists = (bool)(await cmd.ExecuteScalarAsync(ct))!;
        }
        if (roleExists)
        {
            await Exec(conn, tx, $"GRANT USAGE ON SCHEMA reporting TO {Ident(options.ReadOnlyRole)}", ct);
            await Exec(conn, tx, $"GRANT SELECT ON ALL TABLES IN SCHEMA reporting TO {Ident(options.ReadOnlyRole)}", ct);
        }
        else log.LogWarning("Role read-only '{Role}' tidak ditemukan; view reporting dibuat tanpa GRANT", options.ReadOnlyRole);
        await tx.CommitAsync(ct);
        log.LogInformation("Skema reporting disinkronkan: {Count} view", views.Count);

        // Sinkron ulang setiap kali metadata dipublikasikan (DocType/field baru langsung bisa di-query).
        if (Interlocked.Exchange(ref _subscribed, 1) == 0 && metadata is MetadataRegistry reg)
            reg.Published += snapshot => _ = Task.Run(async () =>
            {
                try { await SyncAsync(); } catch (Exception ex) { log.LogError(ex, "Sinkronisasi skema reporting gagal"); }
            });
    }

    private static async Task Exec(NpgsqlConnection c, NpgsqlTransaction tx, string sql, CancellationToken ct)
    {
        await using var cmd = new NpgsqlCommand(sql, c, tx);
        await cmd.ExecuteNonQueryAsync(ct);
    }
}

/// <summary>
/// Menjalankan query widget: koneksi read-only yang diverifikasi, tenant dikunci per sesi, transaksi READ ONLY,
/// statement_timeout, dibungkus LIMIT, parameter dikirim native (bukan digabung ke teks SQL).
/// </summary>
public sealed class PostgresReportingQueryExecutor(NpgsqlDataSource appDb, ReadOnlyDataSource roDb, ReportingOptions options,
    ILogger<PostgresReportingQueryExecutor> log) : IReportingQueryExecutor
{
    private volatile string? _verified;

    public bool IsAvailable => true;

    /// <summary>Menolak connection string yang ternyata bukan read-only (bisa menulis, superuser, atau bisa membaca tabel inti).</summary>
    private async Task VerifyReadOnlyAsync(NpgsqlConnection ro, CancellationToken ct)
    {
        if (_verified == ro.ConnectionString) return;
        // Tabel dicari lewat katalog (OID), bukan nama "public.x": user read-only yang benar memang tidak punya USAGE
        // pada skema public, dan resolusi nama akan gagal. Hak tabel dicek langsung pada OID-nya.
        const string sql = """
            WITH t AS (
                SELECT c.relname, c.oid FROM pg_class c JOIN pg_namespace n ON n.oid = c.relnamespace
                WHERE n.nspname = 'public' AND c.relname IN ('docframe_documents', 'docframe_users', 'docframe_reporting_sessions')
            )
            SELECT current_user,
                   r.rolsuper OR r.rolcreaterole OR r.rolcreatedb OR r.rolbypassrls,
                   EXISTS (SELECT 1 FROM information_schema.role_table_grants g
                           WHERE g.grantee = current_user AND g.privilege_type IN ('INSERT','UPDATE','DELETE','TRUNCATE')),
                   COALESCE((SELECT has_table_privilege(current_user, t.oid, 'SELECT') FROM t WHERE t.relname = 'docframe_documents'), false),
                   COALESCE((SELECT has_table_privilege(current_user, t.oid, 'SELECT') FROM t WHERE t.relname = 'docframe_users'), false),
                   COALESCE((SELECT has_table_privilege(current_user, t.oid, 'SELECT,INSERT,UPDATE,DELETE') FROM t WHERE t.relname = 'docframe_reporting_sessions'), false),
                   COALESCE((SELECT has_schema_privilege(current_user, n.oid, 'CREATE') FROM pg_namespace n WHERE n.nspname = 'reporting'), false)
            FROM pg_roles r WHERE r.rolname = current_user
            """;
        await using var cmd = new NpgsqlCommand(sql, ro);
        await using var r = await cmd.ExecuteReaderAsync(ct);
        if (!await r.ReadAsync(ct)) throw new ReportingUnavailableException("Role read-only tidak ditemukan");
        var problems = new List<string>();
        if (r.GetBoolean(1)) problems.Add("role punya hak superuser/create");
        if (r.GetBoolean(2)) problems.Add("role punya hak INSERT/UPDATE/DELETE");
        if (r.GetBoolean(3)) problems.Add("role bisa membaca tabel dokumen langsung (melewati isolasi tenant)");
        if (r.GetBoolean(4)) problems.Add("role bisa membaca tabel akun");
        if (r.GetBoolean(5)) problems.Add("role punya hak atas tabel sesi pelaporan");
        if (r.GetBoolean(6)) problems.Add("role bisa membuat objek di skema reporting");
        var user = r.GetString(0);
        if (problems.Count > 0)
        {
            log.LogError("Connection string read-only ditolak ({User}): {Problems}", user, string.Join("; ", problems));
            throw new ReportingUnavailableException($"Koneksi dashboard bukan read-only yang aman ({user}): {string.Join("; ", problems)}. Gunakan user khusus SELECT pada skema reporting.");
        }
        _verified = ro.ConnectionString;
    }

    public async Task<QueryResultSet> ExecuteAsync(string tenantId, string parameterizedSql, IReadOnlyList<SqlParam> parameters, int limit, CancellationToken ct = default)
    {
        var sw = Stopwatch.StartNew();
        await using var ro = await roDb.Source.OpenConnectionAsync(ct);
        try { await VerifyReadOnlyAsync(ro, ct); }
        catch (PostgresException ex) { throw new ReportingUnavailableException($"Gagal memverifikasi koneksi read-only: {ex.MessageText}"); }
        var pid = ro.ProcessID;
        await using (var reg = appDb.CreateCommand(
            "INSERT INTO docframe_reporting_sessions (pid, tenant_id, created_at) VALUES ($1, $2, now()) ON CONFLICT (pid) DO UPDATE SET tenant_id = $2, created_at = now()"))
        {
            reg.Parameters.AddWithValue(pid); reg.Parameters.AddWithValue(tenantId);
            await reg.ExecuteNonQueryAsync(ct);
        }
        try
        {
            await using var tx = await ro.BeginTransactionAsync(IsolationLevel.RepeatableRead, ct);
            await using (var set = new NpgsqlCommand($"SET TRANSACTION READ ONLY; SET LOCAL statement_timeout = '{Math.Clamp(options.StatementTimeoutSeconds, 1, 120)}s'", ro, tx))
                await set.ExecuteNonQueryAsync(ct);

            // Pembungkus LIMIT: query yang salah tulis tidak bisa membawa jutaan baris ke memori aplikasi.
            await using var cmd = new NpgsqlCommand($"SELECT * FROM (\n{parameterizedSql}\n) AS __q LIMIT {limit + 1}", ro, tx);
            foreach (var p in parameters)
                cmd.Parameters.Add(new NpgsqlParameter
                {
                    Value = p.Value ?? DBNull.Value,
                    NpgsqlDbType = p.Type switch
                    {
                        ParamTypes.Number => NpgsqlDbType.Numeric,
                        ParamTypes.Date => NpgsqlDbType.Date,
                        ParamTypes.Boolean => NpgsqlDbType.Boolean,
                        ParamTypes.Text => NpgsqlDbType.Text,
                        _ => throw new QueryRejectedException("Tipe parameter tidak didukung"),
                    },
                });

            var rows = new List<object?[]>();
            var truncated = false;
            List<ResultColumn> columns;
            await using (var r = await cmd.ExecuteReaderAsync(ct))
            {
                columns = Enumerable.Range(0, r.FieldCount).Select(i => new ResultColumn(r.GetName(i), Kind(r.GetFieldType(i)))).ToList();
                while (await r.ReadAsync(ct))
                {
                    if (rows.Count == limit) { truncated = true; break; }
                    var row = new object?[r.FieldCount];
                    for (var i = 0; i < r.FieldCount; i++) row[i] = r.IsDBNull(i) ? null : Normalize(r.GetValue(i));
                    rows.Add(row);
                }
            }
            await tx.RollbackAsync(ct);
            return new QueryResultSet(columns, rows, truncated, sw.ElapsedMilliseconds);
        }
        catch (PostgresException ex)
        {
            throw new QueryRejectedException(ex.SqlState switch
            {
                PostgresErrorCodes.QueryCanceled => $"Query melebihi batas waktu {options.StatementTimeoutSeconds} detik",
                PostgresErrorCodes.InsufficientPrivilege => $"Akses ditolak: {ex.MessageText}. Query hanya boleh membaca view di skema reporting.",
                PostgresErrorCodes.ReadOnlySqlTransaction => "Query mencoba mengubah data; hanya SELECT yang diizinkan.",
                _ => ex.MessageText,
            });
        }
        finally
        {
            await using var del = appDb.CreateCommand("DELETE FROM docframe_reporting_sessions WHERE pid = $1");
            del.Parameters.AddWithValue(pid);
            await del.ExecuteNonQueryAsync(CancellationToken.None);
        }
    }

    private static string Kind(Type t) =>
        t == typeof(decimal) || t == typeof(int) || t == typeof(long) || t == typeof(short) || t == typeof(double) || t == typeof(float) ? "number"
        : t == typeof(DateTime) || t == typeof(DateOnly) || t == typeof(DateTimeOffset) ? "date"
        : t == typeof(bool) ? "boolean" : "text";

    private static object? Normalize(object v) => v switch
    {
        int i => (decimal)i, long l => (decimal)l, short s => (decimal)s, double d => (decimal)d, float f => (decimal)f,
        DateTime dt => dt.TimeOfDay == TimeSpan.Zero ? dt.ToString("yyyy-MM-dd", CultureInfo.InvariantCulture) : dt.ToString("yyyy-MM-dd HH:mm", CultureInfo.InvariantCulture),
        DateOnly d => d.ToString("yyyy-MM-dd", CultureInfo.InvariantCulture),
        DateTimeOffset o => o.ToString("yyyy-MM-dd HH:mm", CultureInfo.InvariantCulture),
        decimal or string or bool => v,
        _ => Convert.ToString(v, CultureInfo.InvariantCulture),
    };
}

public static class ReportingServiceCollectionExtensions
{
    /// <summary>
    /// Mengaktifkan dashboard SQL. Wajib bersama AddDocFrameworkPostgreSql. <paramref name="readOnlyConnectionString"/>
    /// harus user database yang hanya punya SELECT pada skema reporting (lihat deploy/sql/reporting-readonly-user.sql).
    /// </summary>
    public static IServiceCollection AddDocFrameworkReporting(this IServiceCollection services, string readOnlyConnectionString, Action<ReportingOptions>? configure = null)
    {
        var options = new ReportingOptions { ReadOnlyConnectionString = readOnlyConnectionString };
        configure?.Invoke(options);
        services.AddSingleton(options);
        services.AddSingleton(_ => new ReadOnlyDataSource(NpgsqlDataSource.Create(readOnlyConnectionString)));
        services.AddSingleton<ReportingSchemaSync>();
        services.Replace(ServiceDescriptor.Singleton<IReportingQueryExecutor, PostgresReportingQueryExecutor>());
        services.Replace(ServiceDescriptor.Singleton<IWidgetStore, PostgresWidgetStore>());
        return services;
    }

    public static Task SyncReportingSchemaAsync(this IServiceProvider services, CancellationToken ct = default) =>
        services.GetService<ReportingSchemaSync>()?.SyncAsync(ct) ?? Task.CompletedTask;
}

        var xi = ColIndex(Visual.XColumn); var yi = ColIndex(Visual.YColumns.FirstOrDefault());
        var list = Result!.Rows.Select((r, i) => new Slice(i, xi >= 0 ? Label(r[xi]) : $"#{i + 1}", Math.Max(yi >= 0 ? Num(r[yi]) ?? 0 : 0, 0))).ToList();
        if (list.Count <= 8) return list;
        var top = list.OrderByDescending(s => s.Value).Take(7).ToList();
        top.Add(new Slice(7, "Lainnya", list.Except(top).Sum(s => s.Value)));
        return top.Select((s, i) => s with { Index = i }).ToList();

    private static string Trim(string s, int max) => s.Length <= max ? s : s[..(max - 1)] + "…";
    private static string Pct(decimal v, decimal total) => total <= 0 ? "0%" : (v / total).ToString("0.#%", Id);
    private static string Full(decimal v) => v.ToString(v == Math.Round(v) ? "#,0" : "#,0.##", Id);

    /// <summary>Singkatan angka gaya Indonesia: 1,2 rb · 3,5 jt · 1,1 M · 2 T.</summary>
    public static string Short(decimal v)
    {
        var a = Math.Abs(v);
        return a >= 1_000_000_000_000m ? (v / 1_000_000_000_000m).ToString("0.#", Id) + " T"
             : a >= 1_000_000_000m ? (v / 1_000_000_000m).ToString("0.#", Id) + " M"
             : a >= 1_000_000m ? (v / 1_000_000m).ToString("0.#", Id) + " jt"
             : a >= 10_000m ? (v / 1_000m).ToString("0.#", Id) + " rb"
             : v.ToString("#,0.##", Id);
    }

    private static (decimal Top, decimal Step) NiceScale(decimal max, decimal min)
    {
        var range = max - min;
        if (range <= 0) return (max <= 0 ? 1 : max * 1.2m, max <= 0 ? 0.25m : max * 0.3m);
        var rough = (double)range / 4;
        var mag = Math.Pow(10, Math.Floor(Math.Log10(rough)));
        var norm = rough / mag;
        var nice = norm <= 1 ? 1 : norm <= 2 ? 2 : norm <= 2.5 ? 2.5 : norm <= 5 ? 5 : 10;
        var step = (decimal)(nice * mag);
        var top = Math.Ceiling(max / step) * step;
        return (top == max ? top + step * 0 : top, step);
    }

    private static string Arc(double cx, double cy, double r, double a0, double a1)
    {
        double X(double a) => cx + r * Math.Cos(a); double Yp(double a) => cy + r * Math.Sin(a);
        var large = a1 - a0 > Math.PI ? 1 : 0;
        return $"M {F(cx)} {F(cy)} L {F(X(a0))} {F(Yp(a0))} A {F(r)} {F(r)} 0 {large} 1 {F(X(a1))} {F(Yp(a1))} Z";
    }

    private List<SelectOption<string>> departments = [];
    private bool loading, designer;
    private string? startText = new DateOnly(DateTime.Today.Year, 1, 1).ToString("yyyy-MM-dd");
    private string? endText = DateTime.Today.ToString("yyyy-MM-dd");
    private string department = "";

    protected override async Task OnInitializedAsync()
    {
        designer = DashboardService.CanDesign(Current.Required);
        if (!Dashboards.IsAvailable) return;
        if (Metadata.Current.TryGet("Department", out _))
        {
            try
            {
                var depts = await Docs.QueryForReportAsync(Current.Required, "Department", [], DocActions.Read);
                departments = depts.OrderBy(d => d.Name).Select(d => new SelectOption<string>(d.Name, d.Data.GetValueOrDefault("department_name") as string ?? d.Name)).ToList();
            }
            catch (PermissionDeniedException) { }
        }
        await Load();
    }

    private DashboardFilters Filters => new(
        DateOnly.TryParse(startText, out var s) ? s : null,
        DateOnly.TryParse(endText, out var e) ? e : null,
        string.IsNullOrEmpty(department) ? null : department);

    private async Task Load()
    {
        loading = true;
        layout = await Dashboards.GetLayoutAsync(Current.Required);
        var list = new List<Card>();
        foreach (var item in layout.Items)
            if (await Dashboards.GetAsync(Current.Required, item.WidgetId) is { } w) list.Add(new Card(item, w));
        cards = list;
        StateHasChanged();
        var filters = Filters;
        // Widget dijalankan paralel; masing-masing memakai koneksinya sendiri dan dibatasi statement_timeout.
        await Task.WhenAll(cards.Select(async c => c.Run = await Dashboards.RunWidgetAsync(Current.Required, c.Widget, filters)));
        loading = false;
    }

    private async Task SaveLayout()
    {
        try { await Dashboards.SaveLayoutAsync(Current.Required, layout); }
        catch (PermissionDeniedException ex) { Toasts.Error(ex.Message, "Gagal"); }
    }

    private async Task Move(Card c, int delta)
    {
        var i = layout.Items.IndexOf(c.Item); var j = i + delta;
        if (i < 0 || j < 0 || j >= layout.Items.Count) return;
        (layout.Items[i], layout.Items[j]) = (layout.Items[j], layout.Items[i]);
        var ci = cards.IndexOf(c); var cj = ci + delta;
        if (cj >= 0 && cj < cards.Count) (cards[ci], cards[cj]) = (cards[cj], cards[ci]);
        await SaveLayout();
    }

    private async Task Resize(Card c)
    {
        c.Item.Span = c.Item.Span >= 3 ? 1 : c.Item.Span + 1;
        await SaveLayout();
    }

    private async Task Unpin(Card c)
    {
        await Dashboards.UnpinAsync(Current.Required, c.Widget.Id);
        layout.Items.Remove(c.Item); cards.Remove(c);
        Toasts.Success("Widget masih tersimpan di Kelola widget.", $"{c.Widget.Name} dilepas");
    }
}

    private static readonly (int, string)[] Steps = [(1, "Query"), (2, "Parameter & pratinjau"), (3, "Visual"), (4, "Simpan")];
    private WidgetDef widget = new();
    private VisualConfig Visual => widget.Config.Visual;
    private int step = 1, maxStep = 1;
    private bool isEdit, notFound, busy, pin = true;
    private string? error, errorTitle;
    private QueryResultSet? preview;
    private string? loadedKey;

    private static readonly IEnumerable<SelectOption<string>> TypeOptions =
        [new(ParamTypes.Text, "Teks"), new(ParamTypes.Number, "Angka"), new(ParamTypes.Date, "Tanggal"), new(ParamTypes.Boolean, "Boolean")];
    private static readonly IEnumerable<SelectOption<string>> BoolOptions = [new("", "(kosong)"), new("true", "Ya (true)"), new("false", "Tidak (false)")];

    private static IEnumerable<SelectOption<string>> BindingOptions(WidgetParameter p)
    {
        yield return new(ParamBindings.Default, "Nilai default (tetap)");
        if (p.Type == ParamTypes.Date) { yield return new(ParamBindings.GlobalStart, "Filter dashboard: tanggal mulai"); yield return new(ParamBindings.GlobalEnd, "Filter dashboard: tanggal akhir"); }
        if (p.Type == ParamTypes.Text)
        {
            yield return new(ParamBindings.GlobalDepartment, "Filter dashboard: departemen");
            yield return new(ParamBindings.UserDepartment, "Departemen pengguna yang melihat");
            yield return new(ParamBindings.UserId, "ID pengguna yang melihat");
        }
    }

    private IReadOnlyList<string> VisualErrors => preview is null ? ["Jalankan pratinjau dulu"] : DashboardService.ValidateVisual(Visual, preview.Columns);

    protected override async Task OnParametersSetAsync()
    {
        if (WidgetId == loadedKey && loadedKey is not null) return;
        loadedKey = WidgetId ?? "";
        if (WidgetId is null) return;
        var w = await Dashboards.GetAsync(Current.Required, WidgetId);
        if (w is null) { notFound = true; return; }
        widget = w; isEdit = true; maxStep = 2;
    }

    private void GoTo(int n) { if (n <= maxStep) { step = n; error = null; } }

    private void Insert(string text)
    {
        var sql = widget.Config.Sql.TrimEnd();
        widget.Config.Sql = sql + (sql.Length == 0 ? "" : " ") + text;
    }

    private void Detect()
    {
        error = null;
        var (analysis, parameters) = DashboardService.DetectParameters(widget.Config.Sql, widget.Config.Parameters);
        if (!analysis.Ok) { (errorTitle, error) = ("Query belum bisa dipakai", analysis.Error); return; }
        widget.Config.Parameters = parameters;
        preview = null;
        step = maxStep = 2;
    }

    private void SetType(WidgetParameter p, string? type)
    {
        p.Type = type ?? ParamTypes.Text;
        p.DefaultValue = null;
        if (!BindingOptions(p).Any(o => o.Value == p.Binding)) p.Binding = ParamBindings.Default;

    private async Task RunPreview()
    {
        error = null; busy = true;
        try
        {
            preview = await Dashboards.PreviewAsync(Current.Required, widget.Config.Sql, widget.Config.Parameters);
            maxStep = Math.Max(maxStep, 4);
            AutoMap();
        }
        catch (Exception ex) when (ex is QueryRejectedException or ReportingUnavailableException)
        {
            preview = null; maxStep = 2;
            (errorTitle, error) = ("Query gagal dijalankan", ex.Message);
        }
        finally { busy = false; }
    }

    /// <summary>Pemetaan awal otomatis: X = kolom teks/tanggal pertama, Y = kolom angka pertama.</summary>
    private void AutoMap()
    {
        var cols = preview!.Columns;
        if (Visual.XColumn is null || cols.All(c => c.Name != Visual.XColumn))
            Visual.XColumn = cols.FirstOrDefault(c => c.Kind is "text" or "date")?.Name ?? cols.FirstOrDefault()?.Name;
        Visual.YColumns.RemoveAll(y => cols.All(c => c.Name != y || c.Kind != "number"));
        if (Visual.YColumns.Count == 0 && cols.FirstOrDefault(c => c.Kind == "number" && c.Name != Visual.XColumn) is { } y) Visual.YColumns.Add(y.Name);
        if (preview.Rows.Count == 1 && cols.Count(c => c.Kind == "number") == 1 && cols.Count == 1 && Visual.Type == ChartTypes.Bar) Visual.Type = ChartTypes.Number;
    }

    private void SetChart(string type)
    {
        Visual.Type = type;
        if (type is ChartTypes.Pie or ChartTypes.Doughnut or ChartTypes.Number && Visual.YColumns.Count > 1) Visual.YColumns = [Visual.YColumns[0]];
    }

    private void ToggleY(string col, bool on)
    {
        if (on)
        {
            if (Visual.Type is ChartTypes.Pie or ChartTypes.Doughnut or ChartTypes.Number) Visual.YColumns.Clear();
            if (!Visual.YColumns.Contains(col)) Visual.YColumns.Add(col);
        }
        else Visual.YColumns.Remove(col);
    }

    private void ToggleRole(string role, bool on)
    {
        if (on && !widget.Config.Roles.Contains(role)) widget.Config.Roles.Add(role);
        if (!on) widget.Config.Roles.Remove(role);
    }

    private async Task Save()
    {
        error = null; busy = true;
        try
        {
            var saved = await Dashboards.SaveAsync(Current.Required, widget, pin && !isEdit);
            Toasts.Success(pin && !isEdit ? "Widget ditempel ke dashboard." : "Widget tersimpan.", $"{saved.Name} v{saved.Version}");
            Nav.NavigateTo(pin || isEdit ? "/dashboard" : "/dashboard/widgets");
        }
        catch (Exception ex) when (ex is QueryRejectedException or ReportingUnavailableException or PermissionDeniedException)
        {
            (errorTitle, error) = ("Widget belum bisa disimpan", ex.Message);
        }
        finally { busy = false; }
    }

    private static string KindLabel(string k) => k switch { "number" => "angka", "date" => "tanggal", "boolean" => "ya/tidak", _ => "teks" };
    public static string ChartLabel(string t) => t switch
    {
        ChartTypes.Bar => "Batang", ChartTypes.Line => "Garis", ChartTypes.Pie => "Pie", ChartTypes.Doughnut => "Doughnut",
        ChartTypes.Number => "Angka tunggal", _ => "Tabel data"
    };
}

    public static async Task SeedAsync(IServiceProvider sp)
    {

        if (!dash.IsAvailable) return;
        var admin = await sp.GetRequiredService<IUserDirectory>().FindAsync("admin");
        if (admin is null || (await dash.ListAsync(admin)).Count > 0) return;

        var range = new List<WidgetParameter>
        {
            new() { Name = "StartDate", Label = "Dari", Type = ParamTypes.Date, DefaultValue = $"{DateTime.Today.Year}-01-01", Binding = ParamBindings.GlobalStart },
            new() { Name = "EndDate", Label = "Sampai", Type = ParamTypes.Date, DefaultValue = $"{DateTime.Today.Year}-12-31", Binding = ParamBindings.GlobalEnd },
        };
        var dept = new WidgetParameter { Name = "Dept", Label = "Departemen", Type = ParamTypes.Text, Binding = ParamBindings.GlobalDepartment };

        async Task Add(string name, string desc, string sql, List<WidgetParameter> ps, VisualConfig v, int span, List<string>? roles = null)
        {
            var w = await dash.SaveAsync(admin, new WidgetDef { Name = name, Description = desc,
                Config = new WidgetConfig { Sql = sql, Parameters = ps, Visual = v, Roles = roles ?? [] } }, pin: true);
            if (span > 1)
            {
                var layout = await dash.GetLayoutAsync(admin);
                layout.Items.First(i => i.WidgetId == w.Id).Span = span;
                await dash.SaveLayoutAsync(admin, layout);
            }
        }

        await Add("Total pengajuan disetujui", "Nilai pengajuan berstatus Disetujui pada periode filter",
            """
            SELECT COALESCE(SUM(total), 0) AS total_disetujui
            FROM reporting.purchase_request
            WHERE workflow_state = @Status AND request_date BETWEEN @StartDate AND @EndDate
              AND (@Dept IS NULL OR department = @Dept)
            """,
            [new() { Name = "Status", Label = "Status", Type = ParamTypes.Text, DefaultValue = "Disetujui" }, .. range, dept],
            new VisualConfig { Type = ChartTypes.Number, YColumns = ["total_disetujui"] }, 1, ["Finance", "Manager"]);

        await Add("Pengajuan per departemen", "Jumlah pengajuan per departemen",
            """
            SELECT department AS departemen, COUNT(*) AS jumlah
            FROM reporting.purchase_request
            WHERE request_date BETWEEN @StartDate AND @EndDate
            GROUP BY department ORDER BY jumlah DESC
            """,
            [.. range], new VisualConfig { Type = ChartTypes.Doughnut, XColumn = "departemen", YColumns = ["jumlah"] }, 1);

        await Add("Karyawan per departemen", "Karyawan aktif menurut struktur organisasi",
            """
            SELECT d.department_name AS departemen, COUNT(e.name) AS karyawan
            FROM reporting.department d
            LEFT JOIN reporting.employee e ON e.department = d.name AND e.active
            GROUP BY d.department_name ORDER BY karyawan DESC
            """,
            [], new VisualConfig { Type = ChartTypes.Pie, XColumn = "departemen", YColumns = ["karyawan"] }, 1);

        await Add("Nilai pengajuan per status", "Total nilai dan jumlah pengajuan per status workflow",
            """

            FROM reporting.purchase_request
            WHERE request_date BETWEEN @StartDate AND @EndDate AND (@Dept IS NULL OR department = @Dept)
            GROUP BY 1 ORDER BY nilai DESC
            """,
            [.. range, dept], new VisualConfig { Type = ChartTypes.Bar, XColumn = "status", YColumns = ["nilai"] }, 2);

        await Add("Tren pengajuan harian", "Jumlah pengajuan per tanggal",
            """

            WHERE request_date BETWEEN @StartDate AND @EndDate
            GROUP BY request_date ORDER BY request_date
            """,
            [.. range], new VisualConfig { Type = ChartTypes.Line, XColumn = "tanggal", YColumns = ["jumlah"] }, 1);

            JOIN reporting.purchase_request p ON p.name = i.parent
            WHERE p.request_date BETWEEN @StartDate AND @EndDate
            GROUP BY i.item_name ORDER BY nilai DESC
            """,
            [.. range], new VisualConfig { Type = ChartTypes.Table }, 3);
    }

-- DocFrame: user database READ-ONLY untuk Dashboard SQL.
-- Jalankan SEKALI sebagai superuser/DBA, sebelum aplikasi dijalankan dengan
-- ConnectionStrings:DocFrameReadOnly. Ganti password!
--
-- User ini:
--   - tidak punya hak INSERT/UPDATE/DELETE/DDL di mana pun,
--   - TIDAK punya akses ke tabel inti (dokumen, akun, file, sesi),
--   - hanya membaca view di skema "reporting" (GRANT SELECT diberikan otomatis oleh
--     aplikasi setiap kali view disinkronkan dari metadata).
-- Aplikasi memverifikasi semua hal di atas sebelum menjalankan query; bila tidak
-- terpenuhi, dashboard menolak berjalan.

DO $$
BEGIN
    IF NOT EXISTS (SELECT 1 FROM pg_roles WHERE rolname = 'docframe_ro') THEN
        CREATE ROLE docframe_ro LOGIN PASSWORD 'ganti-password-ini'
            NOSUPERUSER NOCREATEDB NOCREATEROLE NOREPLICATION NOBYPASSRLS
            CONNECTION LIMIT 20;
    END IF;
END $$;

GRANT CONNECT ON DATABASE docframe TO docframe_ro;

ALTER ROLE docframe_ro SET default_transaction_read_only = on;

ALTER ROLE docframe_ro SET idle_in_transaction_session_timeout = '30s';

    /// <summary>Satu "instance aplikasi". Dengan PostgreSQL, beberapa provider berbagi database yang sama.</summary>
    private static async Task<IServiceProvider> BuildProviderAsync(Action<IServiceCollection>? extra = null)
    {
        var services = new ServiceCollection();
        services.AddLogging(b => b.SetMinimumLevel(LogLevel.Warning));
        services.AddSingleton<IConfiguration>(new ConfigurationBuilder().AddInMemoryCollection(new Dictionary<string, string?>
        {
            ["Print:Letterheads:acme:CompanyName"] = "PT Acme Nusantara Teknologi",
        }).Build());
        services.AddDocFramework(o => o.LoadFrom(Path.Combine(AppContext.BaseDirectory, "Metadata")));
        services.AddDocHandler<PurchaseRequestHandler>();
        services.AddFieldValidator<NpwpValidator>();
        services.AddEventHandler<WorkflowNotificationHandler>();
        services.AddReport<SpendByDepartmentReport>();
        services.AddDocFrameworkIdentity();
        if (PgConnection is not null) services.AddDocFrameworkPostgreSql(PgConnection);
        if (PgReadOnly is not null) services.AddDocFrameworkReporting(PgReadOnly, o => o.StatementTimeoutSeconds = 2);
        extra?.Invoke(services);
        // ValidateScopes = perilaku Development: menangkap service ber-scope yang di-resolve dari root provider.
        var sp = services.BuildServiceProvider(new ServiceProviderOptions { ValidateScopes = true });
        if (PgConnection is not null) await sp.MigrateDocFrameworkDatabaseAsync();
        if (PgReadOnly is not null) await sp.SyncReportingSchemaAsync();
        return sp;
    }

    private static async Task ResetDatabaseAsync()
    {
        await using var db = NpgsqlDataSource.Create(PgConnection!);
        // Kunci advisory yang sama dengan ReportingSchemaSync: tunggu sinkronisasi view (dipicu publish di test sebelumnya) selesai.
        await using var cmd = db.CreateCommand("SELECT pg_advisory_lock(90595631526516); DROP SCHEMA IF EXISTS reporting CASCADE; DROP SCHEMA public CASCADE; CREATE SCHEMA public; SELECT pg_advisory_unlock(90595631526516);");
        await cmd.ExecuteNonQueryAsync();
    }

    [Test]
    public Task Ekspresi_dievaluasi_dengan_proyeksi_list_dan_operator_in()
    {
        var fns = FunctionRegistry.CreateDefault();
        var ev = new ExpressionEvaluator(fns);
        var data = new Dictionary<string, object?>
        {
            ["status"] = "Tinggi",
            ["items"] = new List<Dictionary<string, object?>> { new() { ["amount"] = 1500m }, new() { ["amount"] = 2500m } },
        };
        var ctx = new EvalContext { Scope = new DictionaryScope(data) };
        Assert.Equal(4000m, ev.Evaluate(new ExpressionParser(fns).Parse("sum(items.amount)"), ctx), "sum");
        Assert.Equal(true, ev.Evaluate(new ExpressionParser(fns).Parse("status in ['Normal', 'Tinggi'] && len(items) == 2"), ctx), "in");
        Assert.Equal(false, ev.Evaluate(new ExpressionParser(fns).Parse("!(1 + 2 * 3 == 7)"), ctx), "presedensi");
        return Task.CompletedTask;
    }

        Assert.True(inbox.ForUser("acme", "budi").Any(n => n.DocName == "PR-2026-00002"), "atasan IT menerima notifikasi");

        Assert.True(inbox.ForUser("acme", "sari").Any(n => n.Subject.Contains("ditolak")), "pemohon menerima penolakan");

        int Count() => users.Values.Sum(u => inbox.ForUser(u.TenantId, u.Id).Count);
        var before = Count();
        var msg = sp.GetRequiredService<IOutboxStore>().Snapshot().First(m => m.Type == "workflow.transitioned");

        Assert.Equal(before, Count(), "pemrosesan ulang tidak menggandakan");

    [Test]
    public async Task Outbox_retry_lalu_dead_letter_saat_handler_gagal()
    {
        var store = sp.GetRequiredService<IOutboxStore>();
        var clock = new ManualClock();
        var processor = new OutboxProcessor(store, [new FailingHandler()], clock);
        for (var i = 0; i < OutboxProcessor.MaxAttempts * 10; i++)
        {
            var r = await processor.ProcessDueAsync();
            if (r.Failed + r.DeadLettered == 0) clock.Advance(TimeSpan.FromMinutes(5)); // batch habis → majukan waktu ke percobaan berikutnya
            if (store.Snapshot().All(m => m.DeadLettered)) break;
        }
        var msgs = store.Snapshot();
        Assert.True(msgs.All(m => m.DeadLettered && m.Attempts == OutboxProcessor.MaxAttempts), "semua pesan masuk dead-letter setelah batas percobaan");
    }

    private sealed class FailingHandler : IEventHandler
    {
        public bool CanHandle(string eventType) => true;
        public Task HandleAsync(OutboxMessage message, CancellationToken ct) => throw new InvalidOperationException("SMTP mati");
    }

    private sealed class ManualClock : TimeProvider
    {
        private DateTimeOffset now = DateTimeOffset.UtcNow;
        public override DateTimeOffset GetUtcNow() => now;
        public void Advance(TimeSpan t) => now += t;
    }

    [Test]
    public Task Editor_operasi_tambah_pindah_kolom_hapus_dan_klasifikasi_risiko()
    {
        var reg = sp.GetRequiredService<MetadataRegistry>();
        var active = reg.Current.Get(PR).Def;
        var d = DocTypeDesign.From(active);
        var tab = d.Tabs.Single(t => t.Title == "Pengajuan");
        var kebutuhan = tab.Sections.Single(s => s.Title == "Kebutuhan");
        var pemohon = tab.Sections.Single(s => s.Title == "Pemohon");

        // Tambah field baru di kolom 2, posisi pertama
        var f = d.AddField("Currency", kebutuhan, 1, 0, reg.Current);
        f.Name = "estimated_shipping"; f.Label = "Ongkos kirim";
        var def = d.ToDef(2);
        var added = def.Fields.Single(x => x.Name == "estimated_shipping");
        Assert.Equal("Kebutuhan", added.Section, "section field baru");
        Assert.Equal(2, added.Column, "kolom field baru");
        Assert.Equal("Pengajuan", added.Tab, "tab field baru");
        var (snap, errs) = reg.CompileDraft(def);
        Assert.True(snap is not null && errs.Count == 0, "draft dengan field baru valid: " + string.Join("; ", errs));
        Assert.Equal(ChangeRisk.Safe, reg.Preview(def).Risk, "menambah field opsional = aman");

        // Pindah 'priority' ke awal section Pemohon kolom 1
        var priority = d.AllFields.Single(x => x.Name == "priority");
        d.Move(priority, pemohon, 0, 0);
        def = d.ToDef(2);
        var moved = def.Fields.Single(x => x.Name == "priority");
        Assert.True(moved.Section == "Pemohon" && moved.Column == 1, "priority pindah ke section Pemohon kolom 1");
        var layout = reg.CompileDraft(def).Snapshot!.Get(PR).Layout;
        var firstInColumn = layout.Single(t => t.Title == "Pengajuan").Sections.Single(s => s.Title == "Pemohon").Columns[0].Fields[0];
        Assert.Equal("priority", firstInColumn.Name, "di form, priority tampil paling atas kolom 1 section Pemohon");

        // Pindah ke bawah di kolom yang sama: indeks setelah elemen dihapus tetap benar
        var col0 = pemohon.Columns[0];
        var first = col0[0]; var third = col0[2];
        d.Move(first, pemohon, 0, 3);
        Assert.True(col0.IndexOf(first) == 2 && col0.IndexOf(third) == 1, "geser ke posisi sesudahnya");

        // Ubah 2 kolom → 1 kolom: field kolom 2 digabung, tidak hilang
        var count = pemohon.Columns.Sum(c => c.Count);
        d.SetColumns(pemohon, 1);
        Assert.Equal(count, pemohon.Columns[0].Count, "jumlah field tetap saat kolom digabung");

        // Tab baru: field di dalamnya mendapat judul tab eksplisit
        var newTab = d.AddTab();
        newTab.Title = "Lampiran";
        d.Move(f, newTab.Sections[0], 0, null);
        Assert.Equal("Lampiran", d.ToDef(2).Fields.Single(x => x.Name == "estimated_shipping").Tab, "field di tab baru");
        Assert.True(!d.RemoveTab(newTab), "tab berisi field tidak bisa dihapus");

        // Hapus field lama = berisiko
        d.Remove(d.AllFields.Single(x => x.Name == "required_by"));
        var pv = reg.Preview(d.ToDef(2));
        Assert.Equal(ChangeRisk.Risky, pv.Risk, "menghapus field lama berisiko");
        Assert.True(pv.Changes.Any(c => c.Path == "fields.required_by" && c.Risk == ChangeRisk.Risky), "diff menyebut field yang dihapus");
        return Task.CompletedTask;
    }

    private static WorkflowDef VendorWorkflow(int version = 1) => new()
    {
        Name = "VendorReview", DocType = "Vendor", Version = version, InitialState = "Draft",
        States = [new() { Name = "Draft", DocStatus = 0 }, new() { Name = "Ditinjau", DocStatus = 1, Tone = "pending" }, new() { Name = "Aktif", DocStatus = 1, Tone = "positive" }],
        Transitions =
        [
            new() { From = "Draft", To = "Ditinjau", Action = "Kirim tinjauan", AllowedRoles = ["Procurement"] },
            new() { From = "Ditinjau", To = "Aktif", Action = "Aktifkan", AllowedRoles = ["Finance"] },
        ],
    };

    [Test]
    public Task Workflow_diff_mengklasifikasikan_risiko()
    {
        var oldWf = VendorWorkflow();
        var added = VendorWorkflow(2);
        added.States.Add(new() { Name = "Ditolak", DocStatus = 2, Tone = "negative" }); added.Transitions.Add(new() { From = "Ditinjau", To = "Ditolak", Action = "Tolak", AllowedRoles = ["Finance"], RequireComment = true });
        Assert.Equal(ChangeRisk.Safe, WorkflowDiff.Compare(oldWf, added).Max(c => c.Risk), "menambah transisi = aman");
        var roles = VendorWorkflow(2); roles.Transitions[1].AllowedRoles = ["Employee"];
        Assert.Equal(ChangeRisk.Risky, WorkflowDiff.Compare(oldWf, roles).Max(c => c.Risk), "mengubah role transisi = berisiko");
        var removed = VendorWorkflow(2); removed.States.RemoveAll(x => x.Name == "Aktif"); removed.Transitions.RemoveAt(1);
        var ch = WorkflowDiff.Compare(oldWf, removed);
        Assert.True(ch.Any(c => c.Path == "states.Aktif" && c.Risk == ChangeRisk.Risky), "menghapus state = berisiko");
        Assert.True(ch.Any(c => c.Risk == ChangeRisk.NeedsTransform && c.Description.Contains("Aktifkan")), "menghapus transisi = perlu transformasi");
        var init = VendorWorkflow(2); init.InitialState = "Ditinjau"; init.States[1].DocStatus = 0;
        Assert.True(WorkflowDiff.Compare(oldWf, init).Any(c => c.Path == "initialState" && c.Risk == ChangeRisk.NeedsTransform), "state awal berubah");
        return Task.CompletedTask;
    }

    [Test]
    public Task Dashboard_parameter_dideteksi_di_luar_string_dan_komentar()
    {
        var a = SqlGuard.Analyze("SELECT dept, COUNT(*) AS n FROM reporting.employee -- @Abaikan\nWHERE status = @Status AND note <> '@BukanParam' AND tgl >= @StartDate AND x = @status /* @Juga */ AND tags @> ARRAY['a'] GROUP BY dept;");
        Assert.True(a.Ok, "query valid: " + a.Error);
        Assert.True(a.Parameters.SequenceEqual(["Status", "StartDate"]), "parameter: " + string.Join(",", a.Parameters));
        Assert.True(a.ParameterizedSql.Contains("status = $1") && a.ParameterizedSql.Contains("x = $1") && a.ParameterizedSql.Contains("tgl >= $2"), "nama sama → placeholder sama");
        Assert.True(a.ParameterizedSql.Contains("'@BukanParam'") && a.ParameterizedSql.Contains("@>"), "string literal & operator @> tidak disentuh");
        Assert.True(SqlGuard.Analyze("WITH x AS (SELECT 1) SELECT * FROM x").Ok, "WITH diizinkan");
        Assert.True(!SqlGuard.Analyze("SELECT 1; DROP TABLE docframe_users").Ok, "multi-statement ditolak");
        Assert.True(!SqlGuard.Analyze("DELETE FROM reporting.employee").Ok, "bukan SELECT ditolak");
        Assert.True(!SqlGuard.Analyze("SELECT $$x$$").Ok, "dollar-quoting ditolak");
        Assert.True(!SqlGuard.Analyze("SELECT 'tidak ditutup").Ok, "string tak ditutup ditolak");
        var (_, ps) = DashboardService.DetectParameters("SELECT * FROM t WHERE a >= @StartDate AND b = @IsAktif AND c > @MinTotal AND d = @Status");
        Assert.True(ps[0].Type == ParamTypes.Date && ps[0].Binding == ParamBindings.GlobalStart && ps[1].Type == ParamTypes.Boolean && ps[2].Type == ParamTypes.Number && ps[3].Type == ParamTypes.Text, "tipe & binding awal ditebak dari nama");
        return Task.CompletedTask;
    }

    private IReportingQueryExecutor Exec => sp.GetRequiredService<IReportingQueryExecutor>();
    private async Task<QueryResultSet> Sql(string tenant, string sql, params object?[] args)
    {
        var a = SqlGuard.Analyze(sql);
        if (!a.Ok) throw new QueryRejectedException(a.Error!);
        var typed = args.Select(v => new SqlParam(v, v switch { decimal => ParamTypes.Number, DateOnly => ParamTypes.Date, bool => ParamTypes.Boolean, _ => ParamTypes.Text })).ToList();
        return await Exec.ExecuteAsync(tenant, a.ParameterizedSql, typed, 100);
    }

    [Test, PgTest]
    public async Task Pg_outbox_tidak_diproses_ganda_oleh_dua_worker()
    {
        var seen = new ConcurrentBag<Guid>();
        var counter = new CountingHandler(seen);
        var sp2 = await BuildProviderAsync();
        var w1 = new OutboxProcessor(sp.GetRequiredService<IOutboxStore>(), [counter], TimeProvider.System);
        var w2 = new OutboxProcessor(sp2.GetRequiredService<IOutboxStore>(), [counter], TimeProvider.System);
        var total = sp.GetRequiredService<IOutboxStore>().Snapshot().Count;
        for (var round = 0; round < 5; round++) await Task.WhenAll(w1.ProcessDueAsync(), w2.ProcessDueAsync());
        Assert.Equal(total, seen.Count, "setiap pesan diproses tepat sekali");
        Assert.Equal(total, seen.Distinct().Count(), "tidak ada pesan ganda");
    }

    private sealed class CountingHandler(ConcurrentBag<Guid> seen) : IEventHandler
    {
        public bool CanHandle(string eventType) => true;
        public async Task HandleAsync(OutboxMessage m, CancellationToken ct) { await Task.Delay(2, ct); seen.Add(m.Id); }
    }

================================================================================
 CATATAN PENTING
================================================================================

- Widget menampilkan data SELURUH TENANT. Aturan cakupan permission DocType
  ("milik sendiri", "sama dengan departemen") tidak berlaku di SQL. Batasi role
  widget untuk data sensitif, atau pakai binding "Departemen pengguna yang melihat".

- Jangan pernah mengisi DocFrameReadOnly dengan connection string utama: aplikasi
  akan menolaknya ("bukan read-only yang aman"), dan dashboard tidak berjalan.

- Database yang sudah ada: migrasi 005 dan view dibuat otomatis saat startup;
  widget contoh hanya dibuat untuk database demo baru.

- Nilai parameter kosong dikirim sebagai NULL; untuk filter opsional gunakan
  (@X IS NULL OR kolom = @X).

- Batas: pratinjau 100 baris, widget 1000 baris, waktu eksekusi 5 detik
  (Dashboard:PreviewLimit / WidgetRowLimit / StatementTimeoutSeconds).

- Query bisa join antar-view (mis. reporting.employee dengan reporting.department).
  View tidak bisa mengakses tabel inti, akun, maupun file.
