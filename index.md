# Welcome to DocFrame

**DocFrame** is a metadata-driven .NET Business Framework inspired by modern extensible enterprise architectures (such as Frappe Framework). Built with **.NET 10**, **ASP.NET Core**, **Blazor Server**, and **Blazor Blueprint UI** (shadcn/ui styling for Blazor).

---

## Key Pillars

1. **DocType & Metadata Engine**: Dynamic schemas, document lifecycle, validations, and versioned publishing.
2. **Document Service**: Unified pipeline handling validation, workflow transitions, outbox events, and audit logging.
3. **Role-Based Security & Permissions**: Granular permissions per DocType and tenant-isolated operations.
4. **Dual Persistence Support**: Seamlessly switch between **In-Memory** (rapid dev/tests) and **PostgreSQL** (production).
5. **Modern Blazor UI**: Responsive web portal with interactive widgets, generic views, and dynamic document forms.
6. **Extensibility & Integrasi**: Hooks, form actions, scheduled jobs, Excel/CSV import/export, and auto-generated query APIs.
